# Passovik

Зашифрованное хранилище паролей для Obsidian. Работает на компьютере, телефоне и планшете.

## Возможности

- **Шифрование всегда включено.** Без мастер-пароля данные на диске не прочитать.
- **Группы, избранное, поиск** по названию, логину, ссылкам и заметкам.
- **Генератор паролей** с настройкой длины и набора символов, индикатор надёжности.
- **Корзина**: удалённые записи можно восстановить, через заданный срок они удаляются навсегда.
- **Резервные копии**: перед изменениями сохраняется зашифрованная копия хранилища.
- **Синхронизация между устройствами** через любой синхронизатор хранилища Obsidian. Изменения с разных устройств объединяются по каждой записи отдельно.
- **Автоблокировка** по бездействию и, по желанию, при сворачивании приложения.
- **Автоочистка буфера обмена** после копирования.
- **Импорт и экспорт CSV**: понимает выгрузки браузеров и большинства менеджеров паролей.
- Интерфейс на русском и английском.

## Как пользоваться

1. Откройте Passovik значком ключа на боковой панели или командой «Открыть хранилище паролей».
2. Придумайте мастер-пароль. **Восстановить забытый мастер-пароль невозможно**, поэтому сохраните его в надёжном месте.
3. Добавляйте записи кнопкой «+».

На широком экране менеджер показывает три колонки: группы, записи и карточку записи. На телефоне колонки открываются по одной, с кнопкой «Назад».

## Где хранятся данные

Всё хранится в папке `Passovik` внутри хранилища Obsidian (папку можно сменить в настройках):

- `vault.json` — зашифрованное хранилище;
- `backups/` — зашифрованные резервные копии.

Папка намеренно не скрытая: скрытые папки (с точкой в начале имени) многие синхронизаторы пропускают.

## Безопасность

- Шифрование AES-256-GCM. Ключ получается из мастер-пароля через PBKDF2-SHA256 с 600 000 итераций и случайной солью.
- Заголовок файла (формат, версия, соль) защищён от подмены: он участвует в проверке целостности.
- Пока хранилище открыто, в памяти находится ключ, а не сам пароль. При блокировке ключ и расшифрованные данные стираются.
- Плагин не обращается к сети.
- Ссылки открываются, только если это `http` или `https`.
- На компьютере буфер обмена очищается через заданное время, если в нём всё ещё скопированное значение. На телефоне очистка срабатывает, только если вы не переключались в другое приложение: мобильные системы не дают проверить содержимое буфера.
- Экспорт в CSV создаёт файл с паролями **открытым текстом**. Удаляйте его сразу после использования.

## Перенос паролей из другого менеджера

1. Выгрузите пароли в CSV из браузера или другого менеджера паролей.
2. Положите файл в хранилище Obsidian.
3. В Passovik откройте меню «⋮» → «Импорт из CSV» и выберите файл.
4. После импорта Passovik предложит удалить исходный файл: в нём пароли открытым текстом.

Распознаются колонки на русском и английском: название / name / title, логин / имя пользователя / username, пароль / password, ссылка / url, заметки / notes, группа / group / folder.

## Установка

### Через BRAT

1. Установите плагин [BRAT](https://obsidian.md/plugins?id=obsidian42-brat).
2. В его настройках выберите «Add beta plugin» и укажите `https://github.com/Zloyso/passovik`.
3. Включите Passovik в настройках Obsidian.

### Вручную

Скачайте `main.js`, `manifest.json` и `styles.css` из [последнего релиза](https://github.com/Zloyso/passovik/releases/latest), положите их в `<хранилище>/.obsidian/plugins/passovik/` и включите плагин.

## Разработка

```bash
npm install
npm run dev     # сборка с отслеживанием изменений
npm test        # тесты
npm run lint
npm run build   # проверка типов и сборка
```

## English

Passovik is an encrypted password vault for Obsidian on desktop and mobile. Entries are always encrypted with AES-256-GCM using a key derived from your master password (PBKDF2-SHA256, 600,000 iterations). It offers groups, favorites, search, a password generator, trash, encrypted backups, auto-lock, clipboard clearing, CSV import/export, and per-entry merging when the vault is synced between devices. Data lives in the `Passovik` folder of your vault. A forgotten master password cannot be recovered.
